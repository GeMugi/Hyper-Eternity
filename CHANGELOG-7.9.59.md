## Hyper Eternity 7.9.59

### New
- **Lock screen widgets**: battery, weather, steps and next alarm/event above the lock screen buttons, with the same glass as the notifications
- **iOS-style heads-up — notification bar**: after the heads-up goes away, a small bar stays below the clock to show there are notifications (optional, with position, size, thickness and opacity settings and a live preview)
- **iOS-style heads-up in landscape**: appears on the clock side instead of the middle of the screen
- **Landscape shade**: the music player can sit in a column next to the notifications
- **Curtain**: new option "Player scrolls with the list" (for use together with HyperTweak)
- **Heads-up "No buttons" (HyperOS 4)**: the expand arrow and the floating-window bar become invisible but keep working

### HyperOS 4
- Fixed System UI restarts when opening the curtain on some devices (GPU) and when removing a conversation from a group
- Curtain: pulling it down over a heads-up, swiping to the control center from anywhere, clock no longer left behind when closing
- Stacked groups: no more larger card behind 2-card stacks or group heads-ups
- Heads-up "No buttons" rewritten: no empty space in conversation heads-ups
- Lock screen curtain buttons keep the same icons as the lock screen

### Other
- Missing English/Spanish translations (page titles, status, etc.)
- Code cleanup

### Install
- Install over the previous version (same package and signature; your settings are kept)
- Restart the System UI or the device
