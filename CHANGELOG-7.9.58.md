## Hyper Eternity 7.9.58

### Fixes
- **Stacked groups (HyperOS 4)**: tapping the first card of an open group now opens the notification instead of stacking the group again. The arrow in the group header ("App (n) ⌄") still collapses it
- **iOS-style shade (curtain)**: notifications no longer cover the flashlight and camera buttons; they stack above them
- **Curtain buttons (HyperOS 4)**: the flashlight and camera icons now come from the lock screen shortcuts (following the applied theme) or from the system icons, never from other images on the screen. They refresh when the theme or the shortcut changes

### Install
- Install over the previous version (same package and signature; your settings are kept)
- Restart the System UI or the device
