## Hyper Eternity 7.9.54

### New
- **New settings app built with miuix**: the same pages (Home, Features, Extensions, Settings, About) with HyperOS 3 components, animated color background, frosted glass cards and a floating navigation bar
- **Privacy rebuilt** in the new app: apps, conversations and contacts to hide
- **Lock screen clock in the iOS-style shade (test)**: uses the same clock style as your lock screen; some styles move up and shrink as you scroll the notifications
- **Reverse stacking under the media player** in the iOS-style shade
- Settings reorganized by category

### Fixes
- Control center opens normally again with the iOS-style shade enabled
- HyperOS 4: app icons in stacked groups
- Removed the HyperOS 4-style glass option

### Install
- Install over the previous version (same package and signature; your settings are kept)
- Restart the System UI or the device
